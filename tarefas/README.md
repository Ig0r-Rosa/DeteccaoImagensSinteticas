# Tarefas do Trabalho Final

Checklist dividido em **5 entregas do Moodle**, com etapas pequenas para **2 pessoas** construírem o resultado final aos poucos.

## Legenda

| Símbolo | Significado |
|---|---|
| **A** | Pessoa A |
| **B** | Pessoa B |
| **A+B** | Fazer juntos |
| `- [ ]` | Marcar quando concluir |

## Divisão sugerida de responsabilidades

| Área | Pessoa A | Pessoa B |
|---|---|---|
| Dados e transformações | Principal | Apoio |
| Modelo e avaliação | Apoio | Principal |
| Gráficos e resultados | Principal | Apoio |
| Estrutura do repositório | Apoio | Principal |
| Poster (diagramação) | Principal | Revisão |
| Slides (conteúdo) | Revisão | Principal |
| Vídeo (gravação/edição) | Apoio | Principal |
| Relatório (texto) | Principal | Apoio |

Trocar papéis em etapas longas para equilibrar a carga.

## Ordem de execução recomendada

A numeração segue o Moodle, mas a **ordem real** depende do que precisa estar pronto antes:

| Ordem | Arquivo | Por quê |

| 5º | [01-relatorio.md](01-relatorio.md) | Consolida tudo antes do envio |

**Prazo único:** **30/11/2026** — todas as 5 entregas no mesmo dia.

## Como usar

1. Começar pelo **02-codigo.md**.
2. Marcar cada checkbox ao concluir.
3. Só avançar para a próxima entrega quando o **critério de pronto** da etapa anterior estiver OK.
4. Revisar sempre em dupla antes de enviar ao Moodle.
